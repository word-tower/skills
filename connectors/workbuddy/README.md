# 在 WorkBuddy 连接词塔

词塔连接器使用 MCP 调用已授权的学习数据和操作，支持课程导入、阅读位置查询、生词、统计、笔记和个人讲解。需要 WorkBuddy 4.23.0 或更高版本。

## 安装和连接

连接器发布后，在 WorkBuddy 的连接器市场搜索「词塔」并安装。

1. 打开词塔 App 的「账户 → Skill 与 Token」，创建一个连接名称清晰的 API Key。
2. 首次测试可以只授权「课程、目录与阅读位置」。正文、生词、统计、导入、笔记写入及个人讲解按需要单独勾选。
3. 回到 WorkBuddy，打开词塔连接器并点击「连接」。
4. 在「词塔 API Key」密码输入框粘贴以 `wtk-` 开头的 Key，提交连接。
5. 对 AI 说「用词塔告诉我最近在读哪本书」。返回书名或明确提示暂无阅读记录，表示该查询成功。

Key 只填写连接表单。WorkBuddy 按连接器配置在本机保存凭证，调用时自动携带，权限由词塔服务端验证。请勿在对话中粘贴 Key。

## 权限调整与断开

在词塔「账户 → Skill 与 Token」调整该连接的权限，回到 WorkBuddy 刷新或重新连接。撤销 Key 后，后续请求将失效。Key 失效时创建新 Key，并在连接表单中更新。

如果工具列表里没有需要的功能，先检查该 Key 的授权和当前套餐可用范围。导入额度与剩余次数以服务端实时返回为准。EPUB 导入需要客户端能够读取并上传用户选择的文件。

## 在其他客户端使用

支持 Streamable HTTP 的客户端可连接同一地址，并在个人凭证配置中填写词塔 API Key。

```text
https://api.wordtower.cn/api/agent/v1/mcp
```

普通 Skill 也可以通过 `npx skills add word-tower/skills -g` 安装，按[词塔 Skill 教程](../../README.md)配置本地 Key。
